# XFER0404

**Error.** Object body has a key without a value.

## What it means

The object body has an odd number of scalar tokens, so one key has no value. Because a bare word can be a key or a symbol value, one missing value shifts every pair after it; the message lists the pairs the parser inferred, so you can see where the shift began.

## An example

From the conformance suite, `invalid/404-single-key`:

```xfer
{ a }
```

```
$ xfer validate example.xfer
example.xfer:1:3: error XFER0404: object body has a key without a value: a value is missing for "a"; the parser paired a=?
```

## How to fix it

Find the first pair in the message whose key and value look swapped, and add the value that is missing just before it.

## In the specification

Section 5.3, [Objects](https://github.com/paulmooreparks/xferlang/blob/v1.0.0-draft.1/spec/xferlang.md#53-objects), of the specification at `v1.0.0-draft.1`.
