# XFER0405

**Error.** Unterminated object or sequence.

## What it means

An object or sequence is opened and the document ends before it is closed.

## An example

From the conformance suite, `invalid/405-unterminated-object`:

```xfer
{ a 1
```

```text
$ xfer validate example.xfer
example.xfer:1:1: error XFER0405: unterminated object or sequence: expected `}`
```

## How to fix it

Add the closing `}` or `]`. The diagnostic is at the bracket that was never closed.

## In the specification

Section 5.4, [Sequences](/page/spec/syntax#54-sequences), of the [specification](/page/spec) at `v1.0.0-draft.1`.
