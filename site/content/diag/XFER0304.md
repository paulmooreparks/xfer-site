# XFER0304

**Error.** Malformed temporal.

## What it means

The token is shaped like a temporal but is not one of the three forms: a full date, a time with seconds, or a date-time. Reduced forms such as `09:30` or `2025-08`, a lowercase `t` or `z`, and a fraction point with no digits are not temporals.

## An example

From the conformance suite, `invalid/304-reduced-time`:

```xfer
09:30
```

```
$ xfer validate example.xfer
example.xfer:1:1: error XFER0304: malformed temporal: a time is HH:MM:SS
```

## How to fix it

Write the full form: `09:30:00`, `2025-08-01`, `2025-08-01T09:30:00Z`. If the value is not meant as a time at all, put it in a string.

## In the specification

Section 4.6, [Temporals](/page/spec/lexical-structure#46-temporals), of the [specification](/page/spec) at `v1.0.0-draft.1`.
