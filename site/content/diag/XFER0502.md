# XFER0502

**Error.** Annotation has no target.

## What it means

An annotation has nothing to attach to: it is the last thing in an object or a sequence, it sits between a key and its value, or the document has no element after it.

## An example

From the conformance suite, `invalid/502-trailing-annotation-in-object`:

```xfer
{ a 1 <! tag x !> }
```

```
$ xfer validate example.xfer
example.xfer:1:7: error XFER0502: annotation has no target: it is the last thing in its collection
```

## How to fix it

Move the annotation to just before the element or pair it describes.
