# XFER0605

**Error.** Element count exceeds limit.

## What it means

The document has more elements than the parser's element limit. The default is 2^31 − 1; a program reading untrusted input may set a much lower one.

## How to fix it

Split the data into several documents, or raise the limit if you control the parser.

Section 3.4, [Limits](/page/spec/text#34-limits), of the [specification](/page/spec) at `v1.0.0-draft.1`.
