# XFER0801

**Error.** Value has the wrong kind for its target.

## What it means

An object mapper was asked to read a value into a type that cannot take that kind of value: a string where an integer is needed, a sequence where an object is needed. The parser does not report this; a library reports it when it maps a document onto a program's types.

## An example

```xfer
{ port "8080" }
```

Read into a type whose `port` is an integer, the string `"8080"` is the wrong kind; write `port 8080`.

## How to fix it

Change the value to the kind the member expects, or change the member's type. The message says what was expected and what was found.
