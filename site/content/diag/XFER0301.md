# XFER0301

**Error.** Leading zero on a decimal integer.

## What it means

A decimal integer other than zero begins with `0`. A leading zero would mean octal in some languages and decimal in others, so XferLang refuses it: `0755` is never 755 or 493.

## An example

From the conformance suite, `invalid/301-leading-zero`:

```xfer
0755
```

```
$ xfer validate example.xfer
example.xfer:1:1: error XFER0301: leading zero on a decimal integer
```

## How to fix it

Write `755` for the decimal value, or `0o755` for the octal one.

Section 4.5, [Numbers](https://github.com/paulmooreparks/xferlang/blob/v1.0.0-draft.1/spec/xferlang.md#45-numbers), of the specification at `v1.0.0-draft.1`.
