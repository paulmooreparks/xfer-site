# XFER0906

**Error.** Malformed JSON.

## What it means

The JSON text is not well-formed JSON, so there is nothing to convert.

## An example

From the conformance suite, `from-json/826-malformed-empty`:

```json

```

```
$ xfer from-json example.json
example.json:1:1: error XFER0906: malformed JSON: unexpected end of text
```

## How to fix it

Correct the JSON at the position given. Trailing commas, comments, single quotes and unquoted keys are not JSON.

## In the specification

Section 8.2, [JSON to XferLang](https://github.com/paulmooreparks/xferlang/blob/v1.0.0-draft.1/spec/xferlang.md#82-json-to-xferlang), of the specification at `v1.0.0-draft.1`.
