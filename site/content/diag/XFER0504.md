# XFER0504

**Error.** Unsupported major version.

## What it means

The document says it was written for a major version of the specification this parser does not implement.

## An example

From the conformance suite, `invalid/504-unsupported-version`:

```xfer
<! xfer 99 !> 1
```

```
$ xfer validate example.xfer
example.xfer:1:1: error XFER0504: unsupported major version: version 99 is not supported; this parser reads version 1
```

## How to fix it

Write `<! xfer 1 !>`, or remove the annotation (a document without it is version 1). A document for a later major version needs a parser for that version.

## In the specification

Section 7, [Annotations (Level 1)](/page/spec/annotations), of the [specification](/page/spec) at `v1.0.0-draft.1`.
