# XFER0506

**Error.** Unknown annotation.

## What it means

The annotation is not one the specification defines (`xfer`, `id`, `tag` and `lang`), or it is malformed: no name, a name that is not an identifier, a body that is never closed with `!>` or is empty, or a value of the wrong kind for its name. The message says which. XferLang 1.0 has no processing instructions, so the annotations of the 0.x language are reported here.

## An example

From the conformance suite, `invalid/506-unknown-annotation-let`:

```xfer
<! let x 1 !> { a 1 }
```

```
$ xfer validate example.xfer
example.xfer:1:1: error XFER0506: unknown annotation: unknown annotation "let"
example.xfer:1:12: error XFER0402: content after the root element
```

## How to fix it

Use one of the four annotations with the value it takes, close the annotation with `!>`, or remove it. Metadata the four do not cover belongs in the data itself, as an ordinary pair.

## In the specification

Section 7, [Annotations (Level 1)](https://github.com/paulmooreparks/xferlang/blob/v1.0.0-draft.1/spec/xferlang.md#7-annotations-level-1), of the specification at `v1.0.0-draft.1`.
