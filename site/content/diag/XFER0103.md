# XFER0103

**Error.** Character cannot begin a token.

## What it means

The character cannot begin any token. XferLang has no tuples, no `+` sign, no leading `.` on numbers, and no `~`, `?`, `(` or `)` outside strings.

## An example

From the conformance suite, `invalid/103-leading-point`:

```xfer
.5
```

```
$ xfer validate example.xfer
example.xfer:1:1: error XFER0103: character cannot begin a token: found "."; a fractional number needs a digit before the point
```

## How to fix it

Write the value in a form the language has: `0.5` for `.5`, `1` for `+1`, a sequence `[ ... ]` for a tuple, or a string for text.

## In the specification

Section 4, [Lexical structure](https://github.com/paulmooreparks/xferlang/blob/v1.0.0-draft.1/spec/xferlang.md#4-lexical-structure), of the specification at `v1.0.0-draft.1`.
