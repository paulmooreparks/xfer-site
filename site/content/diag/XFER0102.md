# XFER0102

**Error.** `<` not followed by `/` or `!`.

## What it means

A `<` opens only two things: a comment, `</ ... />`, and an annotation, `<! ... !>`. Here it is followed by something else.

## An example

From the conformance suite, `invalid/102-angle-not-comment-or-annotation`:

```xfer
<"legacy explicit string">
```

```text
$ xfer validate example.xfer
example.xfer:1:1: error XFER0102: `<` not followed by `/` or `!`
example.xfer:1:2: error XFER0402: content after the root element
example.xfer:1:26: error XFER0101: scalar token not followed by a separator: found ">"
```

## How to fix it

If the `<` is meant as text, put it inside a string. If it begins a comment or an annotation, add the `/` or `!` after it.
