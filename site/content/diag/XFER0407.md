# XFER0407

**Error.** Token in key position is not an identifier or string.

## What it means

A key must be an identifier or a string. Here a number, a temporal, a keyword or a bracket is where a key should be. A key that spells a keyword, such as `true`, has to be written as a string.

## An example

From the conformance suite, `invalid/407-keyword-as-key`:

```xfer
{ true 1 }
```

```
$ xfer validate example.xfer
example.xfer:1:3: error XFER0407: token in key position is not an identifier or string: found the keyword true
```

## How to fix it

Write the key as a string (`"true"`, `"2025"`), or, if a value has been left out before it, add the value.

## In the specification

Section 5.3, [Objects](/page/spec/syntax#53-objects), of the [specification](/page/spec) at `v1.0.0-draft.1`.
