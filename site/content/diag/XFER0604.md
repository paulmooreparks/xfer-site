# XFER0604

**Error.** Delimiter run exceeds length limit.

## What it means

A delimiter run (the quotes or `#` around a string, or the slashes of a comment) is longer than the parser's limit, which is at least 64. The canonical writer chooses delimiters so that this happens only for content that has quote runs of every length up to the limit, which no ordinary document has.

## How to fix it

Write the string with a shorter delimiter: one longer than the longest quote run in its content is enough, or use the hash form.

## In the specification

Section 3.4, [Limits](https://github.com/paulmooreparks/xferlang/blob/v1.0.0-draft.1/spec/xferlang.md#34-limits), of the specification at `v1.0.0-draft.1`.
