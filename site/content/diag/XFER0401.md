# XFER0401

**Error.** Document has no element.

## What it means

The document holds whitespace and comments, or nothing at all, but no value. A document is exactly one element.

## An example

From the conformance suite, `invalid/401-empty-document`:

```xfer

```

```
$ xfer validate example.xfer
example.xfer:1:1: error XFER0401: document has no element
```

## How to fix it

Add the value. An empty document is usually an empty object `{}` or an empty sequence `[]`.
