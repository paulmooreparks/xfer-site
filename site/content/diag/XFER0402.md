# XFER0402

**Error.** Content after the root element.

## What it means

Something other than whitespace or a comment follows the root element. A document holds one element, and several values side by side are not one document.

## An example

From the conformance suite, `invalid/402-trailing-content`:

```xfer
{ } 1
```

```
$ xfer validate example.xfer
example.xfer:1:5: error XFER0402: content after the root element
```

## How to fix it

Wrap the values in a sequence `[ ... ]` or an object, or remove what follows the root. An annotation after the root is reported here too, because it has nothing after it to attach to.

## In the specification

Section 5.1, [Document](https://github.com/paulmooreparks/xferlang/blob/v1.0.0-draft.1/spec/xferlang.md#51-document), of the specification at `v1.0.0-draft.1`.
