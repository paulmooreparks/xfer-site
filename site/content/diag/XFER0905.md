# XFER0905

**Warning.** Duplicate key in JSON source; last value kept.

## What it means

The JSON object has the same key twice. JSON allows it and most readers keep the last value, so the converter does the same and warns, because an XferLang object may not have duplicate keys.

## An example

From the conformance suite, `from-json/825-duplicate-keys-keep-the-last-value`:

```json
{"a":1,"b":2,"a":3}
```

```
$ xfer from-json example.json
{
    a 3
    b 2
}
example.json:1:14: warning XFER0905: duplicate key in JSON source; last value kept: duplicate key "a"
```

## How to fix it

Remove the duplicate from the JSON, keeping the value you mean.
