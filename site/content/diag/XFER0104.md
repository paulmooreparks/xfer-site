# XFER0104

**Error.** Unterminated comment.

## What it means

A comment opened with `<` and a run of `/` never meets the closing run of exactly as many `/` followed by `>`. A run of a different length is content, so a comment opened with `<//` is not closed by `/>`.

## An example

From the conformance suite, `invalid/104-unterminated-comment`:

```xfer
</ never closed
{ a 1 }
```

```
$ xfer validate example.xfer
example.xfer:1:1: error XFER0104: unterminated comment
example.xfer:3:1: error XFER0401: document has no element
```

## How to fix it

Close the comment with the same number of slashes it opened with. To comment out a region that already has comments in it, open with one more slash than any comment inside it.

## In the specification

Section 4.1, [Comments](/page/spec/lexical-structure#41-comments), of the [specification](/page/spec) at `v1.0.0-draft.1`.
